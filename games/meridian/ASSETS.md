# Asset credits

Meridian ships **no third-party art or audio files**. Every texture, model, sound and piece of music is generated by the game's own code.

The background images in `public/backgrounds/` are original renders made for this game by `assets-src/blender/render_backgrounds.py`: every mountain, building, sky and figure in them is built from code by that script, then rendered with Blender's Cycles. No downloaded models, textures, photos or fonts are used in them.

|---|---|---|---|

| `public/backgrounds/chNN-pano*.webp` | 360° distant backdrop for each chapter | same | Same as this repository |
| `public/backgrounds/chNN-card.webp` | Chapter-select card for each chapter | same | Same as this repository |
