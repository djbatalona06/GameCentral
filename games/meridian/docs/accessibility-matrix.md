# Accessibility Matrix

Each feature is mapped to the **Xbox Accessibility Guidelines (XAG 101–118)** and the **Game Accessibility Guidelines (GAG)** levels (Basic / Intermediate / Advanced). All options are in Settings → Accessibility, which is the first tab. Three presets are offered on first launch.

| Feature | Where | XAG | GAG |
|---|---|---|---|
| First-launch accessibility setup with presets (Vision, Hearing, Motor) | First run | General XAG guidance (surface settings before play) | Intermediate: presets |
| Text size 0.8–1.6× (menus and HUD) | A11y | 101 Text display | Basic: legible default; Intermediate: adjustable |
| Subtitles on by default; size S/M/L/XL; background opacity | A11y | 104 Subtitles and captions | Basic: subtitles; Intermediate: size, background |
| Speaker names and colours | A11y | 104 | Intermediate: speaker identification |
| On-screen sound indicators with direction | A11y | 103 Additional channels for visual and audio cues | Advanced: visual cues for important sounds |
| Threat indicators (who is noticing or attacking you) | A11y | 103 | Intermediate |
| Directional damage arcs | HUD | 103 | Basic |
| Colour-blind correction (protanopia, deuteranopia, tritanopia) with strength | A11y | 102 Contrast, 103 | Intermediate: colour-blind support |
| Information never relies on colour alone (meter shape, laser thickness, text labels) | Design | 103, 109 Object clarity | Basic |
| High-contrast mode (dark world, red enemies, yellow interactables, blue player) | A11y | 102, 109 | Intermediate |
| Readable greybox affordances: chalk ledge edges, treasure beams, grapple rings | Design | 109 | Basic |
| Large reticle | A11y | 109 | Intermediate |
